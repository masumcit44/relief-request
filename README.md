# ReliefRequest - Flood Help Request Board [M4]

Flood Help Request Board for Bangladesh (Feni, Noakhali, Cumilla).
A victim opens one link, taps 2 buttons, and their GPS + people count reach a rescuer map in real time.

## Tech Stack
- Next.js 14 (App Router, TypeScript)
- Tailwind CSS
- Supabase (Postgres + Realtime)
- React-Leaflet 4 + Leaflet
- Vercel

## How to Run
```bash
npm install
npm run dev
```
Open `http://localhost:3000` for the victim form, and `http://localhost:3000/rescuer` for the rescuer dashboard.
